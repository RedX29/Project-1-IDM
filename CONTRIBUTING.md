# Contributing to IDM Activator

Thanks for your interest in contributing! 🎉

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Project-1-IDM.git
   ```
3. **Create a branch** for your feature:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Test your changes** before submitting
5. **Commit** your changes:
   ```bash
   git commit -m 'Add amazing feature'
   ```
6. **Push** to your fork:
   ```bash
   git push origin feature/amazing-feature
   ```
7. Open a **Pull Request** on the original repo

## Reporting Issues

- Check if the issue already exists
- Include your **IDM version** and **Windows version**
- Describe the problem clearly with steps to reproduce

## Code Style

- Keep the batch script clean and readable
- Add comments where necessary
- Test on Windows 10/11 before submitting

## Questions?

- Discord: `onlyvyrex`
- GitHub Issues: [https://github.com/RedX29/Project-1-IDM/issues](https://github.com/RedX29/Project-1-IDM/issues)
